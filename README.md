# Skylots AI Assistant

Терминальный инструмент для мониторинга аукционов Skylots.

## Возможности

- мониторинг одного или нескольких поисковых профилей;
- индивидуальные интервалы сканирования;
- сохранение лотов и истории изменения цен в SQLite;
- отдельные панели HOT и завершающихся лотов;
- избранное, сортировка и компактный режим dashboard;
- ротация журнала приложения;
- управление профилями с клавиатуры.

Фильтрация по ключевым словам и спискам продавцов, Telegram-уведомления
и AI-анализ пока находятся в плане развития.

## Установка

Требуется Python 3.12 или новее.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Запуск

Обычный режим мониторинга:

```bash
.venv/bin/python app.py
```

Один цикл сканирования:

```bash
.venv/bin/python app.py --once
```

`main.py` и `watcher.py` сохранены как совместимые точки входа и запускают
тот же интерфейс, что и `app.py`.

## Управление dashboard

- `Tab`, `←`, `→` — переключить панель;
- `↑`, `↓` — выбрать строку;
- `Enter` — открыть выбранный лот или изменить профиль;
- `F` — добавить лот в избранное;
- `V` — показать только избранные лоты;
- `O` — переключить сортировку по времени, цене или названию;
- `X` — переключить компактный режим;
- `S` — запустить сканирование вручную;
- `Q` — выйти.

Контекстная строка внизу dashboard показывает дополнительные команды для
выбранной панели.

## Данные и настройки

- `settings/config.json` — основные настройки приложения;
- `settings/profiles.json` — поисковые профили;
- `settings/favorites.txt` — ссылки на избранные лоты;
- `data/skylots.db` — лоты и история цен;
- `logs/skylots.log` — журнал приложения.

Корневой `config.json` является устаревшим и приложением не используется.
Он сохранён, чтобы не удалять существующий пользовательский файл без
отдельного подтверждения.
