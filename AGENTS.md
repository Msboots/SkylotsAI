# Skylots AI

## Language

- Общайся с пользователем только на русском языке.
- Все объяснения и планы пиши на русском.
- Код, имена файлов, функций, классов и переменных оставляй на английском.
- Git commit messages пиши на английском.

## Development Rules

- Не изменяй parser.py без моего разрешения.
- Не переименовывай существующие файлы.
- Соблюдай текущую архитектуру проекта.
- Используй pathlib вместо os.path, где это возможно.
- Используй type hints.
- Перед большими изменениями сначала покажи план.
- После успешных изменений создай git commit.
- Не удаляй пользовательский код без подтверждения.
